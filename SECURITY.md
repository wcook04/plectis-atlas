# Reporting a security issue

Use [GitHub's private vulnerability report form](https://github.com/wcook04/plectis-atlas/security/advisories/new)
for security issues in the Atlas site or its build tools. Include the affected
commit or page, a minimal reproduction and the impact you observed. Do not
include credentials or private contributor material.

The current `main` branch is the supported development version. Reports are
handled by a solo maintainer on a best-effort basis.

Atlas renders a pinned public release and attributed outside records. A source
document is input data; its contents should not be executed as instructions.
Building the site does not run Lean or Comparator. Report a paper conversion,
statement pairing or attribution error through [Contributing](CONTRIBUTING.md);
those reports need the specific source and reading, not a security claim.

Keep vulnerability details private until a coordinated disclosure is agreed.
